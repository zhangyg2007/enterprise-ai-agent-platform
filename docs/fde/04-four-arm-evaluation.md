## 3. 采集与评分步骤

1. 从冻结case清单选出全部案例，核对四组题号/期望答案完全一致。挑战题含未知ID、缺字段、权限越界、证据不足、过期制度和恶意文档指令。
2. 先用小样本验证采集流程，小样本结果标为试跑，不用于正式比较。
3. 依次加载四组，保留每题输入摘要、原始回答、错误类型、引用和计时。单卡顺序运行，记录预热；不要让训练或索引任务抢GPU后忽略影响。
4. 两名评审按冻结规则独立评分，隐藏组别标签；不同意见保留并由指定负责人裁定。人工评审人员和日期：____。
5. 校验每组都有N个记录、无重复题号、没有遗漏错误题；失败/未执行仍保留分母，整体未完整运行不放行正式比较。
6. 汇总配对变化和退步案例，再提出可验证改进。原始结果不覆盖，下一轮另建实验ID。
