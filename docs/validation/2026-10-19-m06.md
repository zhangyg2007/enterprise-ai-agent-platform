## 验证环境与边界

本地 Windows，已有 Python 3.13.11，标准库测试；没有安装 PyTorch、LLaMA-Factory、tokenizer 或模型，没有启动数据库、Ollama、训练与 WebUI。服务器目标为 Ubuntu 24.04 / Python 3.11 / RTX4090D 24GB；本地 Python 版本不等于服务器训练版本。

测试使用独立临时目录。GPU、第三方模块与 tokenizer 行为使用测试替身，模型目录使用明确标注的结构 fixture；其中的字节不能当作真实 safetensors 权重。通过这些测试只能说明准备逻辑、接口调用和错误分支符合预期。

## 独立审核与修复

首轮只读代码审核发现两项 P2，均有定向复现：

1. `token_lengths` 在验证后重新读取配置和数据，可能对已变化的数据出具通过报告。要求实际计算使用同一份经过摘要校验的内存快照，并记录受检摘要。
2. `preflight` 仅核对传入 Factory 目录的 HEAD，未绑定实际导入位置。要求核对实际导入包、指定目录、固定提交及已跟踪源码是否被修改。

2026-10-20 最终验证：两项修复已通过独立复审，无剩余阻断交付的P1/P2。实际受检数据改用带摘要的内存快照，Factory检查绑定实际导入路径、版本及已跟踪源码状态。
