## 服务器验收入口

在完成第 1、2 课操作后执行：

```bash
python -m enterprise_ai.db health
python -m enterprise_ai.db verify data/generated/tiny.json
```

`verify` 检查真实数据库内容、同数据集重复导入、角色属性、RLS/表所有权、两个租户各自可见范围、本人假期、会话变量冒充、只读账号写入拒绝、身份映射表保护、跨租户外键、三条查询的计算结果和探针事务回滚。

该命令需要管理员与读者账号，且只针对本教学数据库。检查中的临时写入探针使用事务回滚；同摘要导入不写业务记录。失败结果须保留并排查，不将退出非零的检查视为通过。
