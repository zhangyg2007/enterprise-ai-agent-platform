| 目录或文件                      | 内容                   | 使用方式              |
| -------------------------- | -------------------- | ----------------- |
| `README.md`                | 总入口、现有能力和章节导航        | 每次开始先看它           |
| `docs/ROADMAP.md`          | M00–M13 的安排、依赖和验收目标  | 判断当前学到哪里          |
| `docs/tutorials/`          | 按 `00`、`01`……编号的操作教程 | **主要学习入口，按顺序阅读**  |
| `docs/data-dictionary.md`  | 数据表、字段、关系和业务口径       | 学 M02 时对照查询       |
| `docs/data-cards/`         | 数据来源、标注、切分和适用限制      | 学 M05 时必读         |
| `docs/validation/`         | 执行过哪些检查、哪些还没验证       | 判断结论的可信范围         |
| `docs/progress/`           | 阶段工作总结和历史问题          | 了解进展；注意记录日期       |
| `docs/superpowers/specs/`  | 模块设计与边界              | 想理解“为什么这样设计”时读    |
| `docs/superpowers/plans/`  | 开发实施计划               | 属于开发记录，不是安装步骤     |
| `src/enterprise_ai/`       | Python 实现代码          | 跟着教程涉及的模块阅读       |
| `tests/`                   | 自动化测试、边界和失败案例        | 理解程序应该接受或拒绝什么     |
| `infra/postgres/init/`     | 数据库角色、表结构和初始化 SQL    | 配合 M01、M02 阅读     |
| `data/samples/`            | 随仓库提交的小型教学样例         | 如 M04 的固定题集       |
| `scripts/`                 | 辅助脚本                 | 仅按教程说明调用          |
| `compose.yaml`             | 数据库容器配置              | 按 M01 在 Ubuntu 使用 |
| `pyproject.toml`           | Python 包信息和依赖声明      | 理解项目安装方式          |
| `.env.example`             | 环境变量模板               | 按教程生成自己的配置        |
| `VERSION` / `CHANGELOG.md` | 课程批次和变更记录            | 更新前查看新增内容         |
